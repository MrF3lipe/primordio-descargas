# Primordio · descargas

Simulador de evolución: criaturas que nacen, comen, se persiguen, mutan y forman especies con nombres ridículos.
Tú eres el Jardinero: diseña tu especie en el Laboratorio, supera desafíos, juega con poderes divinos… en 2D o 3D.

## Descargar
Ve a **[Releases](../../releases/latest)** y baja:

- **PC (Windows):** `Primordio-PC-Windows.zip` → descomprímelo y abre `Primordio.exe`.
  Si Windows avisa ("Windows protegió tu PC"), pulsa *Más información → Ejecutar de todas formas* (no está firmado).
- **Android:** `Primordio-Android.apk` → ábrelo en el móvil y permite *instalar apps desconocidas*. Se juega en horizontal.

## Primeros pasos
Empieza por **Tutorial**. **H** = ayuda con los controles, **K** = Bichopedia.
Si va lento: *Ajustes → Calidad visual: Baja* (y vista 2D).

Versión de prueba hecha con Godot 4.6.
